# Run
```
zig build run
```

# Setup

Packages required for building latest `zig`
```
sudo dnf install libglvnd-devel libX11-devel libXcursor-devel libXi-devel libXinerama-devel libXrandr-devel
```

Packages required by `raylib`
```
sudo dnf install libglvnd-devel libX11-devel libXcursor-devel libXi-devel libXinerama-devel libXrandr-devel
```
